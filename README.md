# ✈️ Flight Attendant Management System

## 📌 Project Overview
The Flight Attendant Management System is a MySQL database project designed to manage flight attendants, flights, schedules, passengers, bookings, payments, training, certifications, and flight incidents.

## 🛠️ Technologies Used
- MySQL
- SQL

## 🗂️ Database Structure
The database contains 12 tables:

1. Airport
2. Department
3. Flight Attendant
4. Flight
5. Flight Schedule
6. Passenger
7. Booking
8. Payment
9. Attendant Assignment
10. Attendant Certification
11. Crew Training
12. Flight Incident

## 📊 Project Highlights
- 12 database tables
- 1,200 records (100 per table)
- Primary and foreign key relationships
- Data insertion, updating, and deletion
- SQL queries for database analysis and management

## 📚 SQL Concepts Covered
- DDL and DML
- SELECT, WHERE, ORDER BY, and GROUP BY
- Aggregate functions
- Joins and subqueries
- Constraints and relationships
- ALTER TABLE operations

## ▶️ How to Run
1. Install MySQL Server and MySQL Workbench.
2. Download the `.sql` file from this repository.
3. Open the file in MySQL Workbench.
4. Execute the script against a fresh database.
5. Explore the tables and queries.

**Note:** Run the full script only once on a fresh database to avoid duplicate-object or duplicate-record errors.
